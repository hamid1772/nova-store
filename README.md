# Nova Store — فروشگاه آنلاین محصولات دیجیتال

## شروع پروژه
1. Node.js نسخه LTS را نصب کنید.
2. پوشه پروژه را در VS Code باز کنید.
3. در ترمینال داخل پوشه، `npm install` را اجرا کنید.
4. سپس `npm run dev` را اجرا کنید و نشانی نمایش داده‌شده (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.
5. برای بررسی نسخه نهایی: `npm run build` و سپس `npm run preview`.

## قابلیت‌ها
- طراحی راست‌چین فارسی (RTL) و واکنش‌گرا برای موبایل، تبلت و دسکتاپ.
- جستجوی محصول، فیلتر دسته‌بندی و مرتب‌سازی قیمت/نام.
- سبد خرید با افزایش و کاهش تعداد، محاسبه مجموع و ذخیره در LocalStorage.
- پیام بازخورد، حالت خالی جستجو و خبرنامه نمایشی.

## ساختار
- `index.html`: نقطه ورود HTML و تنظیمات زبان.
- `src/main.jsx`: داده نمونه، منطق و اجزای React.
- `src/styles.css`: ظاهر، حالت‌های واکنش‌گرا و مدیاکوئری‌ها.

## نکته
این پروژه نسخه فرانت‌اند/دمو است. ورود، پرداخت، ارسال سفارش و خبرنامه به بک‌اند واقعی نیاز دارند. تصاویر محصول در این نسخه از ایموجی‌های جایگزین استفاده می‌کنند و قابل تعویض با عکس‌های واقعی هستند.
