# Nova Store — نسخه ویرایش‌شده

فروشگاه React + Vite با رابط فارسی RTL و واکنش‌گرا.

## امکانات این نسخه
- تغییر تم روز و شب؛ انتخاب کاربر در مرورگر ذخیره می‌شود.
- استفاده از آیکون‌های React Icons به جای نمادهای متنی/ایموجی در رابط.
- favicon اختصاصی در `public/favicon.svg`.
- سه بنر طراحی‌شده با تم‌های رنگی متفاوت و کنترل‌های جابه‌جایی (دکمه و نقطه‌ها).
- فیلتر و جستجوی محصولات، سبد خرید و ذخیره سبد در LocalStorage.

## نصب و اجرا
1. Node.js LTS را نصب کنید.
2. در CMD یا ترمینال وارد پوشه پروژه شوید.
3. نصب وابستگی‌ها:
   ```bash
   npm install
   ```
4. اجرای سرور توسعه:
   ```bash
   npm run dev
   ```
5. ساخت نسخه انتشار:
   ```bash
   npm run build
   ```

اگر وابستگی React Icons نصب نشده، با `npm install` پکیج آن نیز نصب می‌شود.
